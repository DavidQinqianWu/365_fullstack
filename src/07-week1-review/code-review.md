# Week 1 代码 self-review

> 用「别人写的代码」的眼光,看一遍 src/01- 到 src/06- 的所有文件。
> 目标:至少找出 3 个问题。一个都没找到 = review 得不够仔细。

## Review 清单(逐条打勾)

- [ ] 有没有用 `readFileSync` 读可能很大的文件(Day 3)
- [ ] 有没有 `body += chunk` 且没有大小上限(Day 3 / 6)
- [ ] 有没有创建 worker / child_process 忘了 terminate / kill(Day 4 / 5)
- [ ] 有没有在主线程做超过 100ms 的同步计算(Day 1 / 5)
- [ ] 错误有没有被吞掉(空 catch、没监听 error 事件)
- [ ] 用 `exec` 的地方有没有拼接外部输入(shell 注入,Day 4)
- [ ] Content-Length 用的是 `.length` 还是 `Buffer.byteLength`(Day 6)
- [ ] 变量名和函数名,一周后的自己看得懂吗
