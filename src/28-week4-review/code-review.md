## Review 清单(逐条打勾,每条写一句「查了什么、结论是什么」)

- [ ] 每一条 SQL 里的「值」都走了参数($1, $2 …)吗?所有用模板字符串拼出来的部分,拼进去的东西是不是都来自代码而不是用户(Day 27)
- [ ] ORDER BY 的列名和方向、schema 名、其他「SQL 结构」是不是都只从白名单里选(Day 19 / 27)
- [ ] 每一个事务的每一条路径(成功、失败、失败时 ROLLBACK 本身也失败)都正确结束了吗?借来的连接一定会还回去吗?还回去的连接还能用吗(Day 27)

- [ ] 有没有请求能绕过 DTO 把「不合法的值」送到数据库?数据库拦下之后返回的是什么(Day 16 / 24 / 27)
- [ ] 内存版和 PG 版对同一个请求的行为是否一致?(排序、时间精度、id 的类型、null……)(Day 27)
- [ ] 约束错误、连接错误、其他数据库错误,有没有把 PG 原文(表名、约束名、SQL)泄露给调用方?没登记的约束违反会变成什么(Day 17 / 24 / 27)
