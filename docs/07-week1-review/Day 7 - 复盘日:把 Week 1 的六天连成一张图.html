🗺️ 第一件事:画出「一个 HTTP 请求的一生」(约 40 min)

任务

在 src/07-week1-review/request-lifecycle.md 里,用文字或 mermaid 画出下面这个过程,每一步标注它对应 Day 几学的内容:

场景

一个德国用户在浏览器输入 https://www.supergood-tech.de/de/day/1/,回车。你的 Node 服务器上发生了什么?

要覆盖这些环节(顺序你自己排):

  • 浏览器发出的那段文本长什么样
  • TCP 连接建立后,谁通知了 event loop
  • event loop 在哪个 phase 取出这个事件
  • 你的 handler 在哪个线程上跑
  • handler 里 await 数据库时,主线程去干嘛了
  • 如果 handler 里有 2 秒 CPU 计算,会发生什么,该怎么办
  • 响应体 100MB 时,该怎么写出去
  • 想吃满 4 核,该用什么
  • 响应报文长什么样,必须有哪几个 header

写完之后自查:这九个环节你标出了几个 Day?

参考答案的对应关系(不是完整答案,只是给你对一下 Day 编号):

环节对应
请求报文格式、状态码、headerDay 6
libuv 通知 → poll phase 取出Day 2
handler 在主线程跑,await 时让出Day 1

为什么这张图值 40 分钟

面试官问「你了解 Node 吗」,背 API 的人说「我用过 Express」;能画这张图的人,直接进入下一轮。

更重要的是:这张图在 C#、Java、Go 里结构完全一样,只有第 3、4 步不同(它们用线程池,不用 event loop)。你画的是「后端服务器」,不是「Node 服务器」。

产出要求

## 文件:src/03-streams-buffer/ex2.ts 第 18 行
**问题:** 用 readFileSync 读了一个可能 2GB 的文件
**后果:** 内存会被吃光,进程崩溃
**改法:** 改成 createReadStream + pipeline

4.2 自测 20 题(闭卷,写在 src/07-week1-review/self-test.md)

基础题(每题 1 分)

  1. 并发和并行的区别是什么?
  2. event loop 的六个 phase,哪三个最重要?
  3. process.nextTick 和 Promise.then,谁先执行?
  4. 为什么递归调用 process.nextTick 会饿死 event loop?
  5. Buffer 和 String 的区别是什么?
  6. write() 返回 false 意味着什么?你该做什么?
  7. pipe() 和 pipeline() 的区别?该用哪个?
  8. 进程和线程,在「内存」这个维度上有什么区别?
  9. exec 的 maxBuffer 是什么?超了会怎样?
  10. cluster 的多个 worker 怎么能监听同一个端口?

理解题(每题 2 分)

  1. 为什么说 worker_threads 不是 cluster 的升级版?
  2. postMessage 的「转移」和「共享」有什么区别?各自什么时候用?
  3. 什么是竞态条件?用一个具体例子说明。
  4. HTTP 请求报文的四个部分是什么?那个空行为什么必须有?
  5. 401 和 403 的区别?
  6. 为什么表单校验失败不该返回 500?
  7. 什么是幂等?POST 和 PUT 哪个幂等?
  8. 什么时候必须用 chunked 而不是 Content-Length?

综合题(每题 5 分)

  1. 场景题:你的 API 有一个 /report 接口,要生成一个 PDF,耗时约 3 秒(纯 CPU)。上线后用户反馈「点了报表,整个网站都卡住了」。用这周学的知识完整解释原因,并给出两个不同层次的解决方案。
  2. 场景题:你的 API 有一个 /export 接口,要导出一个 2GB 的 CSV。目前的实现是先在内存里拼好字符串再返回。说出至少三个问题,并给出改法。改完之后,响应头会有什么变化?
